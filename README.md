## Favicon and Images

You will find the public directory. Inside that you will need to create two sub-directories:

- favicon
- images

The **/favicon.ico** will automatically resolve to the path **/public/favicon/**. Every other favicon image must be prefixed with the **/favicon/** prefix; similar to any images you place within the **/public/images/** directory - which will be prefixed by **/images/** prefix.
